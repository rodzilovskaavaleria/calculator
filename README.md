# Calculator

Практическая работа 20.1 — приложение-калькулятор кредита с конвертацией валюты.

## Проект

Приложение на Python с графическим интерфейсом (tkinter). 
Умеет:
- рассчитывать ежемесячный платёж, сумму всех платежей и начисленные проценты по кредиту
- конвертировать сумму кредита из рублей в выбранную валюту
- сохранять и загружать курсы валют в базу данных SQLite
- обновлять курсы валют через API Центробанка РФ

## Технологии

- Python 3.13
- tkinter — графический интерфейс
- sqlite3 — база данных
- requests — HTTP-запросы к API
- API ЦБ РФ: https://www.cbr-xml-daily.ru/daily_json.js
